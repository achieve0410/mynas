# Security Policy

## Supported versions

Security support begins with the first public v0.1.0 release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting on the public repository after release. Include the
affected version, reproduction steps, and impact without real credentials or
personal data.

The project will acknowledge a complete report within seven days and publish a
coordinated advisory when a fix is available.
